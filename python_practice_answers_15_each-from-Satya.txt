=== Variables & types ===
1. Explain the difference between `==` and `is`. When should you use each?
`==` compares **values**; `is` compares **object identity**.

```python
a = [1, 2]
b = [1, 2]
print(a == b)  # True
print(a is b)  # False
```

Use `is` for singletons like `None`:
```python
x = None
print(x is None)  # True
```

Python variables are **names** bound to objects; the same name can reference objects of different types.

```python

x = [1, 2, 3] # list
```

6. What’s the difference between `list(a)` and `a.copy()` and `copy.deepcopy(a)`? When do you need deep copy?
- `list(a)` and `a.copy()` make a **shallow copy** (nested objects are shared).
- `copy.deepcopy(a)` copies nested objects too.

```python
import copy
a = [[1], [2]]
b = a.copy()           # shallow
c = copy.deepcopy(a)   # deep
a[0].append(99)
print(b)  # [[1, 99], [2]]  (changed!)
print(c)  # [[1], [2]]
```

```python
def timer(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        out = fn(*args, **kwargs)
        dur = time.perf_counter() - start
```

53. Show the 'late binding' gotcha with lambdas in a loop and how to fix it.
Gotcha:
```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)
print([f() for f in funcs])  # [2,2,2]
```
Fix (bind i as default arg):
```python
funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)
print([f() for f in funcs])  # [0,1,2]
```

```python
class BankAccount:
    def __init__(self, initial=0):
        if initial < 0:
            raise ValueError("negative balance")
        self._balance = initial

    @property
    def balance(self):
        return self._balance

    def deposit(self, amt):
        if amt <= 0:
            raise ValueError("deposit must be positive")
        self._balance += amt

    def withdraw(self, amt):

        self._balance -= amt
```
